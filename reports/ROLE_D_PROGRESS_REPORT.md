# Отчёт по роли D: биологический анализ

**Статус на 25 сентября 2026 года:** описательный функциональный анализ выполнен. Статистические межгрупповые сравнения и визуализация остаются следующими этапами.

## Цель роли D

Роль D отвечает за интерпретацию гибкости LBD: функциональные сайты, статистику, визуализацию и текст. На текущем этапе подготовлен воспроизводимый анализ заранее определённых функциональных сайтов пяти рецепторов: VDR, PPARG, ESR1, NR3C1 (GR) и NR4A1.

## Выполненная работа

1. Составлена литературно подтверждённая таблица `reports/tables/functional_site_definitions.csv`.
2. Таблица содержит 44 позиции в канонической нумерации UniProt:
   - VDR: лигандный карман и AF-2/coactivator groove;
   - PPARG: лигандный карман и AF-2/coactivator groove;
   - ESR1: лигандный карман, AF-2/coactivator groove и LBD-гомодимеризация;
   - GR: лигандный карман, AF-2/coactivator groove и D-loop димеризации;
   - NR4A1: Tyr453 и сегмент H12 (584-595).
3. Для каждой позиции указаны UniProt accession, идентификатор сайта, источник и краткая биологическая интерпретация.
4. Добавлен скрипт `scripts/31_analyze_functional_site_bfactors.py`.
5. В `README.md` описаны команда запуска, входные данные и границы применимости анализа.

## Метод анализа

Этот отчёт воспроизводит исторический strict-QC анализ, выполненный до уточнения профессора о сохранении всех структур. Скрипт использует `data/processed/structures_primary_qc_subset.csv` и `data/processed/final_lbd_residue_map_primary_qc_subset.parquet`. Эти 1,382 структуры являются аналитическим QC-подмножеством, а не полным текущим master dataset.

1. Берутся только остатки с `ca_bfactor_usable=True` и конечным `selected_ca_b_iso_or_equiv`.
2. Raw B-факторы нормализуются в Z-score отдельно внутри каждой выбранной receptor instance. Это исключает прямое сопоставление абсолютных B-факторов между кристаллическими структурами.
3. Если в одной PDB-записи присутствует несколько выбранных сущностей одного рецептора, значения для позиции объединяются медианой.
4. Посайтовый балл PDB-записи равен среднему Z-score заданных остатков только при полном покрытии сайта; неполные сайты сохраняются для QC с пустым баллом.
5. Посайтовый балл рецептора равен медиане полных посайтовых баллов по PDB-записям.
6. Вместе с баллом сохраняются число остатков сайта, число доступных остатков, покрытие сайта, число PDB-записей и QC нормализации.

Скрипт создаёт три выходных файла в `reports/tables/`:

- `functional_site_normalization_qc.csv`;
- `functional_site_entry_scores.csv`;
- `functional_site_receptor_scores.csv`.

## Результаты описательного анализа

Нормализация успешно выполнена для всех 1,382 выбранных receptor instances. Получено 1,603 строк PDB-entry site QC и 12 receptor-site summaries, включая две явные строки VDR без данных. Полное покрытие сайта и пригодный site score имеются у 1,590 из 1,603 строк (99.2%).

Эти значения описывают относительное положение функционального сайта внутри распределения C-alpha B-факторов каждой структуры. Например, отрицательный site Z-score ESR1 LBD homodimerization указывает на более низкий относительный B-фактор этого сайта в анализируемых структурах ESR1; он не доказывает повышенную устойчивость димера в растворе.

В этом историческом strict-QC анализе VDR не имеет site scores, потому что все VDR структуры не прошли прежний порог >=90% LBD coverage. После уточнения профессора upstream handoff был исправлен: VDR сохранён в текущем master `structures.csv` (52 candidates; 48 с coordinate data) и присутствует в `lbd_residue_bfactors_all.parquet`. Поэтому отсутствие VDR scores в таблицах данного отчёта отражает только старое strict-QC аналитическое подмножество и не означает отсутствие VDR из проекта. Функциональный анализ VDR следует повторить на новом all-structure handoff с явно заданными критериями анализа.

Позиции PPARG из Nolte et al. приведены в нумерации PPARgamma1. Для согласования с канонической последовательностью UniProt P37231 (PPARgamma2) применён документированный сдвиг +28: ligand pocket 317/351/477/501 и AF-2 329/499. После исправления полное покрытие имеется у 315 из 322 PDB для ligand pocket и у 319 из 322 PDB для AF-2.

## Ограничения интерпретации

- Z-score описывает относительную гибкость внутри структуры; это не прямое измерение динамики белка в растворе.
- Повышенный B-фактор может быть связан с конформационной гетерогенностью, но также с кристаллической упаковкой, неполной электронной плотностью, заселённостью или особенностями refinement.
- Apo/holo-анализ не выполняется этим скриптом: состояния сильно несбалансированы и должны сравниваться только внутри рецептора после проверки достаточного числа структур.
- Для NR4A1 нельзя переносить стандартный набор остатков глубокого лигандного кармана других ядерных рецепторов; отдельно рассматриваются Tyr453 и H12.
